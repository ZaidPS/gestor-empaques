
## Uso

1. Abre `index.html` en un navegador moderno (Chrome, Edge, Firefox).
2. Ingresa con:
   - **admin / admin123** → todos los permisos
   - **editor / editor123** → crear, editar, importar
   - **visor / visor123** → solo lectura y comentar

## Módulos

| Módulo | Responsabilidad |
|---|---|
| `Auth` | Login, logout, permisos por rol |
| `DB` | CRUD sobre datos (hoy localStorage) |
| `Render` | Toda la capa visual y paginación |
| `Modals` | Modales de detalle y edición |
| `Excel` | Importación masiva y exportación |
| `Utils` | Helpers |

## Migrar a backend real

Toda la capa de datos está aislada en `assets/js/db.js`. Para migrar a Firebase, Supabase o tu API REST, solo reemplaza los métodos `load`, `save`, `add`, `update`, `remove` manteniendo las firmas.
